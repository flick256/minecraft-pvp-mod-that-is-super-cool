# SparBot 4.1.0

[Download the mod](sparbot-4.1.0.jar). Replace your previous SparBot jar; keep Fabric API installed.

Requires Minecraft Java 26.2, Java 25, Fabric Loader 0.19.3 or newer and Fabric API 0.161.0+26.2 or newer.

This update fixes compact menu and kit editor overlaps and adds an offline study routine: a question on world entry pays for the first fight, and later SparBot fights and drills require another. Home → Open study provides extra practice. Hints, worked feedback, written self-review and spaced review support learning.

The 72 original VCE-style practice questions cover Sunset Boulevard, Protest and argument analysis; Mathematical Methods; Chemistry; French; and the French and Russian revolutions. They supplement course materials and are not official VCAA questions or full curriculum coverage. The default schedule uses the supplied Melbourne exam dates for October–November 2026.

Validated with 248 unit tests, all 146 required Minecraft server GameTests, and real Minecraft client checks for study, compact layouts, the 4.0 game flows and closing two worlds with live bots. The packaged classes were compared byte for byte with the tested compiled classes.
